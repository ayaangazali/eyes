## Why
Before deploy the app has to run the real Stripe routes and real photo storage, refuse a live start that would silently skip safety and vision, let a crawler or agent find the docs from `/`, and stop wasted or hostile capture uploads before they are read.

## What
- `server.ts`: `stripeRoutes` mounted at `/` (the three-path forward is gone); `liveProviders.storage` is live with `EYES_PROVIDERS=live` and `INSFORGE_API_KEY`; GET `/` home page; `/robots.txt` and `/agents.md` join the docs routes; every docs response and `/` carry `Link: </llms.txt>; rel="describedby", </openapi.json>; rel="service-desc"`; `url` and `*Url` fields in the agent card that start with `/` become absolute from `public_api_url`; docs dir is `EYES_DOCS_DIR` or repo `docs/public`; capture checks the offer (claimed by this worker, status `claimed`) before reading the body and allows 4 uploads at once (429 `rate_limited` after that); unknown routes get a JSON 404; `dispute_answer` text says the payout is held only if not yet paid.
- `http.ts`: URLs parsed with a fixed `http://localhost` base, so Host never matters; an unparsable target is a 400 `invalid_input`; logs redact any `<base64url>.<base64url>` segment of 16+ characters per side, anywhere in the path.
- `main.ts`: `createInsforgeStorage(env)` in live mode; exits with a clear message when `EYES_PROVIDERS=live` and `ANTHROPIC_API_KEY` is unset.

## Decisions & alternatives rejected
- JSON 404 is a `*` middleware that rewrites Hono's plain-text 404 after `next()`. `server.app.notFound` never runs: mcp-use mounts `server.app` into an outer Hono app with `route("/")`, which drops the sub-app's notFound (reproduced). A catch-all route would shadow `/mcp`.
- The capture pre-check reuses `service.getOffer` and mirrors the engine's own `submitCapture` checks, so the answer matches what the engine would say, only earlier. The upload cap is an in-process counter: one instance in the demo.
- `EYES_DOCS_DIR` is the one new env knob: tests serve fixture docs without touching `docs/public` (owned by ax-builder), and T2.3 can point a `--root-dir apps/mcp` deploy at a copied docs folder. It is not in `.env.example`, which this task does not own.
- Token redaction keys on the token shape, not on route prefixes, so new link routes are covered; the 16-character minimum keeps file names such as `llms.txt` readable.

## Assumptions
- Agent card links follow the AX PR #9 layout (`docs/public/.well-known/agent-card.json`, relative `url` and `documentationUrl`).
- `getOffer(token)` throws `offer_invalid` for unknown or expired offers (engine, T1.2).
