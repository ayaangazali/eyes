## Why
Builders are forbidden from guessing sponsor APIs. Seven parallel research nodes fetched each sponsor's docs (llms.txt first) and wrote one builder-ready note each, so every integration starts from cited facts.

## What
- stripe.md, inkbox.md, primitive.md, insforge.md, mcp-use-manufact.md, armature.md, hackathon.md.
- Each note lists sources, env vars, exact calls, webhook verification, limits, contradictions with the spec, and open questions.

## Decisions & alternatives rejected
- One node per sponsor instead of one researcher: disjoint files, parallel, and a failed sponsor does not block the others.
- Contradictions were promoted to ADR-002 and ADR-004 rather than silently applied.

## Assumptions
- Notes reflect docs fetched 2026-10-16. The mcp-use note also ran a local test server against mcp-use@2.10.0.
