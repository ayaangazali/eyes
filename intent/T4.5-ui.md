## Why
A stranger gets a cold text, taps a link and has about 60 seconds to trust it and finish. The UX audit found a dead end (camera blocked on iPhone left no way to take the photo), no way back after a location deny, a blank white loading screen, no brand, and no SMS consent before JOIN. The dashboard is read from a projector during the 90-second demo (§13) and rendered at 9 to 13 px with worker dots that were near invisible.
## What
Findings fixed (index from the audit's findings.json):
- 0 Camera `NotAllowedError` now shows the existing `#fallback` file input (`capture="environment"`, styled as the primary button) with a "Camera access is blocked" note, instead of throwing a dead-end error.
- 1, 2 Location deny gives iPhone steps (aA > Website Settings > Location, or Location Services > Safari Websites) plus an Android line. Capture shows a `Try location again` button that calls `locate()`; JOIN relabels its location button to the same text. No typed address: `/w/join` takes lat/lng only.
- 3 `#task` is no longer hidden, so "Loading your task" shows before the API answers; a failed load sets the h1 to "We could not open this task" (22).
- 4 Dark header bar with the dashboard's amber eye mark on JOIN, capture and privacy pages; og:title/og:description and theme-color on JOIN and capture.
- 5 After the shutter the live video hides and the preview takes its place; Retake shows the live view again. Send and its hint sit in a sticky bottom dock. Video and preview cap at 55vh with `object-fit: contain` so portrait streams do not push Send off screen.
- 6 Copy under the form: closing the page is fine, the task closes at the deadline and the agent is refunded. No new API.
- 8 Before Join: pay ($3 usually, each text shows the amount, paid through Stripe), consent to task texts, msg and data rates, reply STOP, a "never photograph faces or people" box above the form, and a link to the new static `privacy.html`.
- 11 Dashboard root font `clamp(16px, 1.6vh, 22px)`, clock drops seconds, step labels, step times, totals captions, row times and phrases at 0.95rem or more.
- 12 Worker dots radius 10, cyan ring on the workers counted in `workers_notified` for active tasks (the existing `notified()` helper, hoisted); basemap filter is now grayscale-inverted-dimmed so the blue POI squares are gone.
- 15 `finish()` clears the countdown interval and hides `#deadline` on every closed screen.
- 16 Result heading follows the status (Verified and paid / Verified, payout pending / Sent, needs a quick review / Sent) and ends with "You can close this page."
- 17 A worker who did not claim the task sees "Another worker already claimed this task" for submitted/verified/paid/needs_review/disputed instead of "A photo was already sent".
- 18 A hint under Send says what is missing: take the photo, waiting for GPS, location needed, or sending.
- 19 Yes/No answers are bordered 44 px choices; the place link is a 44 px block.
- 20 `.secondary` text is #1a50e0 (5.5:1 on #e8eeff).
- 21 JOIN marks the first invalid field `aria-invalid` + `aria-describedby="error"` and focuses it (location: the location button); `#closed` has `role="status"`.
- 22 "Questions? Reply HELP to the Eyes text." on every capture screen (HELP is wired in the engine). Not added to JOIN, where the reader has no Eyes text yet.
- 23 Headline uses the first comma segment of `place_label`; the empty chip is hidden.
- Coordinator add-on: `rate_limited` (PR #37 join throttle) maps to "Too many sign-ups from this network right now. Wait up to an hour, then try again."
Not done here (other owners): 7, 9, 10, 13, 14, 24.
## Decisions & alternatives rejected
- CARTO `dark_nolabels`/`dark_all` (the audit's suggestion): rejected, the tiles now render an "API KEY REQUIRED" watermark without a key. Kept OSM tiles and changed only the CSS filter.
- Retake is two taps (show live view, then shoot) rather than shooting blind from a hidden video.
- JOIN pay copy says "usually $3 (each text shows the amount)" because `bounty_usd` ranges 1 to 50; a flat "$3 per check" would be untrue for some tasks.
- The HELP line is static HTML on the capture page rather than appended by JS to each error, so it covers loading, closed and error states with no code.
- `[hidden] { display: none; }` without `!important` (biome lint); the preview selector became `img` so the attribute still wins over it.
## Assumptions
- iOS Safari opens the native camera for `<input type="file" capture="environment">` even when the site's camera permission is denied (the audit's premise; not verified on a device here).
- Safari's aA menu wording is "Website Settings > Location"; on newer iOS it may be the page menu icon. The Settings app path is given as the second route.
