## Why
Nine builders need one toolchain and one CI definition so that a green PR means the same thing for every lane, and so that CI runs with zero secrets.

## What
- pnpm workspace (`apps/mcp`, `apps/web/*`, `packages/*`, `cli`), TypeScript 7 strict, Biome, Vitest projects (unit, contract, integration, safety), Playwright.
- `ci.yml` with the ten required jobs; integration and e2e run against a Postgres 17 service container.
- Non-blocking `safety-llm-eval.yml`, `claude-verifier.yml`, `live-smoke.yml`; each skips cleanly when its secret is absent.

## Decisions & alternatives rejected
- Turbo dropped (ADR-003): one root tsc/vitest/biome run covers the workspace and libraries have no build step to cache.
- Libraries ship TypeScript source; Node 24 runs it directly (verified: importing `@eyes/core` through the pnpm symlink works without a loader), so no tsx or bundler.
- `--passWithNoTests` on every test script so empty projects stay green until builders add tests.

## Assumptions
- gitleaks-action v2 needs no license on a personal account repo.

## Verification
- Local: `pnpm lint`, `pnpm typecheck`, `pnpm test:contract` (10 passed), `pnpm test:integration` (4 passed on Postgres 17), `pnpm intent:check`.
- CI: first run on `main` recorded in STATUS.md at G0.
