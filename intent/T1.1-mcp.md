## Why
Agents reach Eyes through this app: eight MCP tools and an identical REST mirror over `EyesService`, plus the public worker API the capture page posts to. It is also the composition root that wires engine, adapters and fakes, so every transport shares the one seam from ADR-003.

## What
- `src/server.ts` `createServer`: mcp-use 2.10.0 server; bearer auth on `/mcp` and `/v1/*` (signup public); all 8 `TOOLS` with exact schemas, annotations and LLM descriptions (example plus next step each); errors as `EyesError.toBody()`; `await_answer` gets the request AbortSignal and reports progress every 5 s when the client sent a token; REST mirror of `HTTP_ROUTES` (`invalid_input` with `issues`); `/w/*` with CORS for `worker_web_url` and a 20 MB capture limit; vendor routes; docs served from `docs/public/<url path>` (so `/.well-known/agent-card.json` reads `docs/public/.well-known/agent-card.json`); `/healthz`.
- `src/geo.ts`: Nominatim `Geo`; `FAKE_PLACES` and "lat,lng" strings resolve first; in-memory cache; 5 s timeout; null on no hit.
- `src/main.ts`: env to `AppConfig` and `DbConfig`; fakes unless `EYES_PROVIDERS=live` plus the adapter's key; one log line per provider; `expireOverdue` every 30 s; listens on `PORT`/`HOST` (3000, 0.0.0.0).

## Decisions & alternatives rejected
- Stripe sub-app is forwarded only for its three paths, not `app.route("/")`: the stub's `all("*")` at `/` shadowed `/mcp` and every 404 (reproduced).
- Tool handlers catch every error: mcp-use returns a thrown error's raw message to the client (reproduced), which leaks internals. Unknown errors are logged server side and become `internal_error`.
- The clock in `main.ts` is always real: `fakeClock` is frozen and would break deadlines and expiry.

## Assumptions
- mcp-use per the vendor note and `dist/*.d.ts`: `c.set` values reach tools through `ctx.get`; `reportProgress` returns false without a progress token; `listen(port, { host })`.
- Nominatim policy wants an identifying User-Agent and at most 1 request/s; the cache keeps demo traffic well below that.
