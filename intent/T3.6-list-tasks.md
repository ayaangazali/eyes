## Why
An agent that loses a task_id (context reset, crash) had no way to find its open tasks, so it asked again and paid twice. The AX eval also found `quote_task` saying `allowed: true` for tasks `ask_eyes` then refused: quote ignored the key's task types, max bounty, daily cap and balance, and its description claimed otherwise.

## What
- `list_tasks({status?, limit=20})`: the calling agent's tasks newest first, max 50, with `answered` and a `next_step` that says resume with `await_answer` / `get_task` before `ask_eyes`. MCP tool, `GET /v1/tasks?status=&limit=`, `eyes tasks [--status] [--limit]`.
- `008_list_tasks.sql`: `eyes_list_tasks(agent_id, status, limit)`, `setof tasks`, filtered on `agent_id`, EXECUTE revoked from public/anon/authenticated.
- `quoteTask` reads `eyes_agent_summary`. `suggested_bounty_usd` = default capped by max_bounty, cap left minus fee and balance minus fee, floored at the 1 USD minimum, in cents. `allowed: false` only for hard blocks (safety, task type not allowed, max_bounty below the minimum, minimum plus fee over the cap left or the balance) with a `reason_if_not` naming amounts, the UTC reset time or `top_up_url`. Description and field docs match; quote still does not see the question.
- Docs regenerated: `llms-full.txt`, `openapi.json` (query parameters for GET routes), agent card; `llms.txt` and `agents.md` mention `list_tasks` and the new quote wording.

## Decisions & alternatives rejected
- `answered` reuses the engine's `ANSWERED` statuses so it agrees with `await_answer`.
- The RPC returns whole task rows and the engine maps them, like `eyes_cancel_task`; `unique (agent_id, idempotency_key)` already serves the `agent_id` filter.
- REST turns `limit` into a number before the strict schema parses it, so MCP input stays a real integer.
- `max_bounty` below the 1 USD minimum is a hard block too: no bounty `ask_eyes` accepts would fit.
- Rejected (orchestrator decision): `allowed: false` whenever the default bounty exceeds a limit, which makes a client that trusts `allowed` give up on the AX eval budget task; a capped-suggestion note in `reason_if_not`; cursor pagination.

## Assumptions
- InsForge RPC returns `setof tasks` rows as a JSON array, as it already does for `eyes_cancel_task`.
