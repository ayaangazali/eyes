## Why
The "Eyes on shift" Shortcut kept a worker's spot fresh by looping (Wait 60 s) while it stayed open, and the worker had to start it by hand. The owner wants no hand-run Shortcuts and no loops: Personal Automations that run by themselves (iOS 26 and macOS 26 both have them, with "Run Immediately"). A small Expo iOS app will also post background fixes and needs its own source value.

## What
- `automation.html` (worker web): iOS 26 steps for automation A (Time of Day 9:00 daily), B (Message from Eyes containing "Eyes ping", body adds `input` = Shortcut Input so the ping counts as answered) and optional C (Charger disconnected). Each is built inline: Get Current Location, then Get Contents of URL (POST `/w/location`, `Authorization: Bearer <code>`, JSON lat/lng/source=shortcut). Copy buttons for the URL, header key, "Bearer " and the ping phrase; the code is never in a URL.
- Texts: AUTO and AUTOMATION map to the existing `shortcut` intent (SHORTCUT still works). The reply links `<EYES_WORKER_WEB_URL>/automation.html`, then texts the new code alone as before. The 401 fix says "or AUTO for a new code".
- Removed: `EYES_SHORTCUT_URL` / `shortcut_url` and the `eyes-on-shift.shortcut` download (with its `_headers`).
- Migration 020 and `WorkerLocationInput.source` add `app` for the Expo app. The `/w/location` contract is otherwise unchanged.
- Production: `EYES_LOCATION_PING=true`, so stale workers (no fix in 24 h) near a task get the "Eyes ping" text that automation B answers.

## Decisions & alternatives rejected
- iOS and macOS 26 Time of Day repeats at most daily, so a few daily times plus the ping trigger replace the loop; the freshness window (24 h) means one daily fix keeps a worker dispatchable.
- Kept the internal intent name `shortcut` (frozen reply-intent contract); only new words map to it.
- launchd plus a CoreLocation CLI on the Mac: rejected, because macOS 26 Shortcuts automations (Time of Day, Message, Wi-Fi) run without a tap and already have location permission.

## Assumptions
- Workers have iOS 26+; iOS 27 moved automations onto shortcuts (Edit, Automation), covered by a one-line note.
- The Message trigger's Sender can be the number Eyes texts from (saved as a contact if needed).
