## Why

The unit check on https://github.com/ayaangazali/eyes/pull/253 failed in the OAuth tampering test.
Replacing a random token's last two characters with `AA` can leave the token unchanged.
The test then sends a valid client ID and incorrectly expects HTTP 400.
The test now changes the first character to a different base64url character for both client IDs and authorization codes.
This changes decoded bytes without relying on the random suffix or base64 padding bits.
The OAuth implementation and test were unchanged by the dependency updates; no dependency rollback is needed.

## Verification

- The original server test file failed with 171 passing tests and HTTP 200 instead of 400 for the tampered client ID.
- A Node.js smoke check reproduced an unchanged `AA` suffix accepted by the token decoder after 110 generated tokens.
- The same check rejected 1,000 tokens with the new first-character mutation.
- `npx -y pnpm@11.18.0 exec vitest run apps/mcp/src/server.test.ts` passed all 172 tests after the fix.
