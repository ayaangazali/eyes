## Why
The worker pages were hand-styled vanilla HTML with no shared vocabulary, and Eyes is meant to become a ChatGPT app, whose widgets must follow ChatGPT's UI rules (system fonts, host neutrals, one brand accent, outline icons, at most two actions per card). A reusable design system lets the worker web, server pages and future ChatGPT widgets share one look without rebuilding it per surface. The backend is untouched: same routes, same `/capture.html?t=` links the server texts workers, same API calls.

## What
- `packages/ui` (`@eyes/ui`): `tokens.css` (ChatGPT apps-sdk-ui palette light and dark, system fonts, 4 px space, system radii, one accent "Viewfinder" #ffd60a), `components.css` (atoms: button, badge, input, choice, icon, link, num, divider, spinner; molecules: field, notice, meta, kv, check, place, viewfinder, steps; organisms: card, carousel, form, capture, status, empty), `icons.svg` (16 outline icons, `i-` ids), `tailwind.css` (Tailwind 4 theme names over the tokens, components in `@layer components`), `chatgpt.css` (maps tokens to the live apps-sdk-ui variables inside a widget).
- `apps/web/worker`: rebuilt on the Better-T-Stack Astro scaffold, as a static site (`output: "static"`, `build.format: "file"`) with Tailwind 4. Pages `index`, `capture`, `privacy` keep their URLs, ids, labels and copy; the existing `join.ts`, `capture.ts` and `api.ts` run unchanged except the class names they assign. New `design/moodboard.html` and `design/catalog.html` show the direction and every element in light and dark.
- Live payouts copy is decided at build time, so the static page is honest before any script runs.

## Decisions & alternatives rejected
- Astro over the Better-T-Stack TanStack Router React SPA: the worker pages must work as static files (InsForge Sites), keep `capture.html`, and show the payout notice with scripts off (an e2e test checks it). A SPA renders nothing without JS.
- Plain CSS classes, not React components: the same markup works in Astro, server-rendered HTML strings and React widgets. React wrappers can come with the first widget.
- Tokens do not read host variables directly: the Tailwind theme defines the same names, and reading them back made a variable cycle that zeroed radii and surfaces. `chatgpt.css` is the opt-in bridge for widgets.
- Icon ids carry an `i-` prefix: unprefixed ids (`message`, `locate`) collided with page element ids the scripts look up.

## Assumptions
- `python3` is on CI runners (Playwright serves the static builds with `python3 -m http.server`; `astro preview` refuses `--ignore-lock` under an AI agent and only runs one server at a time).
